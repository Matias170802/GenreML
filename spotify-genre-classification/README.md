# spotify-genre-classification

## Pregunta de investigación

¿Es posible predecir el género musical de una canción utilizando únicamente sus características de audio?

## Fuente de datos

https://huggingface.co/datasets/maharshipandya/spotify-tracks-dataset

## Primera etapa

El objetivo de la primera etapa es construir un pipeline automatizado de Ingeniería de Datos que obtenga y procese el dataset.
